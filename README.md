# DSA Problem Log

A single-page tracker for practising DSA with LeetCode, built for Java beginners.
No install, no sign-in. Your progress is saved in your own browser.

**Live:** https://vanshsrivastv.github.io/dsa-tracker/

## What's inside
- 47 beginner-friendly LeetCode problems, grouped from loops and arrays up to ArrayList
- A roadmap of 14 topics (Collections and DSA patterns) to tick off in order
- Odometer, gauges, streak and a 6-month activity log
- Tick a problem and it's counted as solved without hints; untick that if you peeked
- Notes, tries and solve date for every problem
- Optional beep sound, and Export / Import so you never lose progress

## How to use
1. Open the link and pick a section from the menu (top left).
2. Tick a problem when you solve it. Open the row for tries, hints and notes.
3. Click **Export** now and then to back up your progress.

## Your data
Everything is stored in your browser's local storage. Nothing is sent anywhere.
Clearing site data erases it, so use Export for a backup.
